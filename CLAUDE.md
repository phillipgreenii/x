# x

Shared Go library module (`github.com/phillipgreenii/x`).

## Go

Go daemons that expose the opt-in pprof endpoint MUST use the shared package
`github.com/phillipgreenii/x/pprofserver` (source in `pprofserver/` in this
repo).

- See also: nix-repo-base `docs/go-daemons.md` (the Go daemons convention).
- See also: nix-repo-base `docs/go-daemon-profiling-runbook.md` (the profiling
  runbook).
